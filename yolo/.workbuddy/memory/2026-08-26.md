## 第二轮: 处理用户上传的视频 iron ball video.mp4
- 视频: 513 帧 / 30 FPS / 1280x720 / 17 秒, 球一直在动 (左→右→左全覆盖)
- 抽帧参数调整经验:
  - step=3 + max-similarity=0.99 + min-blur=40 → 只出 36 张 (球动得慢, 重复判定误杀)
  - step=2 更糟 (相邻帧更像)
  - **最终: step=3 + max-similarity=1.0 (关掉去重) + min-blur=35 → 158 张**
  - 经验: 球持续运动的视频, 重复帧过滤帮倒忙, 建议关掉 (max-similarity 1.0)
- 管道识别放宽: recognition final.py 的 is_quad_like_pipe 顶点数从 4<=v<=12 改为 3<=v<=12
  (原因: 管道一端被球/画面边缘遮挡时多边形合并成 3 个点, 其他指标都合格, 纯属误杀)
  - 修改后 158 张全部标注成功, no_pipe = 0
- 标注质量: 158 张全部合法, 分数中位 0.94, 99%>=0.8, 球 x 覆盖 0.136~0.799 (归一化)
- 下一步: 用户人工检查 dataset/review/, 然后写 train_yolo.py
